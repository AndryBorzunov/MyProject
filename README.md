# MyProject
## Проект реализует домашние задания учебного курса "Python разработчик"

### masks.py
- функции маскировки номера банковской карты и номера счета (9.1)
### widget.py
- обработчик инормации о банковских карте и счете (9.2)
### processing.py
- фильтрация и сортировка списка словарей (10.1)

### Тестирование модулей
- Для создания тестовых модулей использовался framework pytest
